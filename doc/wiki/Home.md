## 框架核心特色速览

1.  **极简依赖，轻量级**：纯 C++17 编写，核心数学层仅依赖 Eigen3，内置轻量级 JSON 解析器，抛弃了复杂的 ROS/ROS2 沉重包袱。
2.  **配置驱动 (Config-Driven)**：无需修改 `main.cpp`，通过一个 JSON 文件即可自由拼装组件、修改参数、定义停止条件和导出日志。
3.  **零拷贝的数据流 (Zero-Copy Data Flow)**：不使用传统 Message 传递带来的拷贝开销。组件之间通过 `ScopedRegistry` 获取指针接口，直接调用方法拉取最新状态。
4.  **高度解耦**：算法工程师只需关注自己的公式，重力、大气、积分器、坐标变换等环境均作为独立组件提供。
